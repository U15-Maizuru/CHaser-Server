# CHaser Server Maizuru

U15プログラミングコンテスト舞鶴大会 向けゲームサーバー。

Python で書かれた AI プログラムを対戦させる **CHaser 系 2人対戦ゲーム**のサーバー実装です。Electron デスクトップアプリとして動作し、リモートブラウザからも操作可能な WebSocket/HTTP API を備えています。

Electron アプリとして1台のPCで動かす**ローカルモード**に加え、`U15_MODE=web` で起動すると
ブラウザから複数のルーム(対戦)を同時に作成・観戦できる**Webサービスモード**としても動作します。
詳細は [docs/developer-manual.md](docs/developer-manual.md#10-マルチルーム--web-サービスモード) を参照してください。

---

## 2ウィンドウ構成

アプリ起動時に**2つのウィンドウ**が開きます。

| ウィンドウ | 用途 |
|---|---|
| **対戦表示ウィンドウ** (1280×800) | ゲームボードを常時表示。プロジェクターや観客用モニターに向ける |
| **コントロールウィンドウ** (1280×800) | プレイヤー設定・プログラム/マップの選択・ゲーム開始など操作専用 |

スロットを「手動操作」にすると、COOL / HOT ごとに**手動操作ウィンドウ** (360×560) も開きます。

## 特徴

**対戦**

- **2ゲーム制** — 公式ルールの試合形式（先攻・後攻を入れ替えた2ゲームで1試合）。勝利数と合計ポイントを自動集計
- **プログラムライブラリ** — `.py` / `.exe` を一度登録すれば全ルームで使い回せる。登録と対戦への割り当ては分離
- **マップライブラリ / マップエディタ** — `.map` の登録と、Canvas ベースの編集。こちらも登録と対戦での使用は分離
- **pychaser ライブラリ対応** — プリインストール済み。カスタムライブラリの追加も可能
- **手動操作モード** — 専用ウィンドウの矢印キー/ボタンで人間がプレイ（デモ・動作確認用）

**大会運営**

- **4つの大会形式** — トーナメント / リーグ / 予選リーグ + 決勝トーナメント / BOT対戦予選 + 決勝トーナメント
- **「今やること」に従うだけの進行** — 準備・開始・確定・決勝進出者の確定が、その時に押すべき1つだけ出る
- **大会データ作成** — 参加者・形式・ルール・組み合わせを画面のフォームで作成。JSON を手書きしなくてよい
- **持ち出し** — 大会データとプログラムを `.zip` に固めて別の PC へ移せる
- **結果の書き出し** — JSON / 試合CSV / 順位CSV
- **オートプレイ** — 大会を最後まで自動で進める（無人展示・リハーサル向け）

**表示・演出**

- **リアルタイム観戦** — WebSocket で複数ブラウザから同時観戦可能。大会中はトーナメント表・順位表も表示
- **盤面上の決着演出** — 勝者に 👑、敗者に敗因バッジ（💥 アタック / 💫 衝突 / 🚧 閉じ込め / 🔒 自縛 / 📵 通信エラー）
- **LOOK / SEARCH の可視化** — 調べた範囲をプレイヤーカラーで盤面に表示
- **BGM / SE / ダークモード** — 会場に合わせた表示・音の設定
- **1ターン表示時間設定** — 各ターンの表示待機時間を調整可能（デフォルト 0.5秒）
- **デモ / リピートモード** — 無人展示向けの自動開始・自動再戦

## ゲームルール概要

準拠する競技ルールの原典は [docs/official/競技ルール.pdf](docs/official/競技ルール.pdf) です。
用語は公式ルールに合わせており、**「ゲーム」= 1回の対戦**、**「試合」= 先攻・後攻を入れ替えた2ゲーム**を指します。

```
マップ上のアイテムを集めて得点を競う 2人ターン制ゲーム (公式マップは 15×17 / 100〜240ターン)

プレイヤーアクション:
  WALK(移動)  LOOK(観察)  SEARCH(探索)  PUT(ブロック設置)

決着理由 (勝利条件):
  アイテム数    →  規定ターン終了時にアイテム数が多い方の勝ち (同数なら引き分け)
  衝突          →  ブロックのあるマスに移動した側の負け
  アタック      →  相手のいるマスにブロックを置いた側の勝ち
  閉じ込め      →  上下左右4方向をブロックで囲まれた側の負け
  自縛          →  自分で自分を4方向から塞いだ側の負け
  通信エラー    →  通信エラーなどで競技を中断させた側の負け (公式ルールの「中断」)
```

ポイント計算（1ゲームぶん）:

| 項目 | ポイント |
|---|---|
| アイテム【両】 | 獲得したアイテム数 × 10 |
| 一撃【勝】 | アタック・閉じ込めでの勝利に +50 |
| 一撃【敗】 | 衝突・自縛・中断（通信エラー）での敗北に −(獲得したアイテム数 × 3) |
| 総取り【勝】 | 決着時に盤面へ残っていたアイテム数 × 6 |

試合の勝者は **① 勝利数 → ② 2ゲームの合計ポイント** の順に決まります（どちらも同点なら、
公式ルールではマップを変更して再試合）。

## 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10/11 |
| Node.js | v20 以上（開発時） |
| pnpm | v8 以上（開発時） |
| Python | 3.8 以上（開発環境で対戦プログラムを実行する場合。配布インストーラー版は Python を同梱するため不要） |

## クイックスタート

```bash
# 依存関係インストール
pnpm install

# 開発モード起動 (Electron + Vite + Backend が同時起動)
# → 対戦表示ウィンドウ と コントロールウィンドウ の2つが開く
pnpm --filter @u15/electron dev

# ビルド (全ワークスペース)
pnpm build
```

## リポジトリ構成

```
U15-server-maizuru/
├── apps/
│   ├── backend/       Node.js ゲームサーバー
│   ├── frontend/      React UI (Vite)
│   └── electron/      Electron シェル (2ウィンドウ管理)
├── packages/
│   └── ws-types/      共有型定義と純関数 (@u15/ws-types)
├── server/            アップロードファイル保存先 (実行時生成)
│   ├── tournament/       大会データ (組み合わせ・進行状態・参加プログラム)
│   ├── program-catalog/  プログラムライブラリ (全ルーム共通)
│   ├── map-catalog/      マップライブラリ (全ルーム共通)
│   ├── music/            BGM ファイル (全ルーム共通)
│   └── rooms/<roomId>/
│       ├── programs/cool/  COOLプレイヤーの対戦用プログラム
│       ├── programs/hot/   HOTプレイヤーの対戦用プログラム
│       ├── libs/cool/      COOLカスタムライブラリ (pyCHaser も自動配置)
│       └── libs/hot/       HOTカスタムライブラリ
├── docs/              マニュアル
│   ├── user-manual.md      ユーザーマニュアル
│   ├── developer-manual.md デベロッパーマニュアル
│   └── official/           競技ルール等の公式資料
├── CLAUDE.md          Claude Code 向けの前提 (用語・構成・コマンド)
├── .claude/skills/    Claude Code 向けの作業知識 (経緯つき)
└── test-screenshots/  E2E テストスクリーンショット
```

> 配布インストーラー版では、`server/` 相当の保存先は OS 標準のユーザーデータフォルダ
> (`app.getPath('userData')`) 配下に作られます。

## 開発

```bash
# 単体テスト
pnpm --filter @u15/backend test
pnpm --filter @u15/frontend test

# E2E 全自動テスト
pnpm test:e2e

# 型チェック (全ワークスペース)
pnpm build

# 個別ビルド
pnpm --filter @u15/ws-types build
pnpm --filter @u15/backend build
pnpm --filter @u15/frontend build

# Windows インストーラー (Python 同梱、apps/electron/release/ に生成)
pnpm --filter @u15/electron build:win
```
