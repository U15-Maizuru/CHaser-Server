## 1. 起動と2ウィンドウ構成

### 起動方法

開発者からインストーラーを受け取った場合はインストール後、アイコンをダブルクリックするだけで起動します。

開発モードで起動する場合:
```bash
pnpm --filter @u15/electron dev
```

### 2ウィンドウ構成

アプリ起動時に**2つのウィンドウ**が自動的に開きます。

```
┌──────────────────────────────────┐   ┌──────────────────────┐
│   対戦表示ウィンドウ              │   │  コントロール         │
│   (1280×800)                    │   │  ウィンドウ           │
│                                  │   │  (820×920)           │
│   [常時ゲームボードを表示]        │   │                      │
│   プロジェクターや観客用          │   │  [チーム設定]        │
│   モニターに映す                  │   │  [ゲーム操作]        │
│                                  │   │  [設定変更]          │
└──────────────────────────────────┘   └──────────────────────┘
```

| ウィンドウ | 役割 |
|---|---|
| **対戦表示ウィンドウ** | ゲームボードを常時表示。セットアップ中は「対戦開始をお待ちください」と両チームの接続状態を表示 |
| **コントロールウィンドウ** | チーム設定・プログラムアップロード・ゲーム開始など全操作はここで行う |

> **運営のヒント**: 対戦表示ウィンドウをプロジェクターに映し、コントロールウィンドウで操作すると、観客に見やすい進行ができます。コントロールウィンドウを閉じるとアプリ全体が終了します。

## 2. コントロールウィンドウ — セットアップ画面

コントロールウィンドウには以下のレイアウトが表示されます。

```
┌────────────────────────────────────────────────────────────┐
│  U15 Server Maizuru  セットアップ  IP: 192.168.1.9  ⚙     │
├──────────────────────────────┬─────────────────────────────┤
│  COOL (青パネル)              │  HOT (赤パネル)             │
│                              │                             │
│  [プログラム][TCP][CPU][手動]│  [プログラム][TCP][CPU][手動]│
│  ⬆ ドロップしてください      │  ⬆ ドロップしてください     │
│                              │                             │
│  カスタムライブラリ ▼         │  カスタムライブラリ ▼        │
├──────────────────────────────┴─────────────────────────────┤
│  マップ  [アップロード...]  [エディタ...]    ゲームスタート  │
└────────────────────────────────────────────────────────────┘
```

- **左パネル (COOL)**: 青チームの設定
- **右パネル (HOT)**: 赤チームの設定
- **フッター**: マップ設定とゲーム開始ボタン
- **ローカル IP**: 外部PCから接続する際のIPアドレス（対戦表示ウィンドウの待機画面にも表示）

## 3. プログラムのアップロード

### 3-1. ドラッグ&ドロップでアップロード

1. コントロールウィンドウのチームパネルの中央ドロップエリアに `.py` ファイルをドラッグしてドロップします
2. アップロード中はプログレスバーが表示されます
3. 完了すると **「✓ ファイル名.py」** と緑色で表示されます
4. 同じ操作を COOL と HOT の両方で行います

### 3-2. クリックして選択

ドロップエリアをクリックするとファイル選択ダイアログが開きます。`.py` または `.exe` ファイルを選択してください。

### 3-3. モードの切り替え

| モード | 用途 |
|---|---|
| **プログラム** | Pythonファイルをアップロードして実行（通常の対戦） |
| **TCP接続** | 外部PCからTCPで接続（IPとポートで接続する場合） |
| **CPU** | 内蔵AIで動作（テスト・動作確認用） |
| **手動操作** | キーボードで人間がプレイ（デモ用） |

### 3-4. カスタムライブラリの追加

「カスタムライブラリ ▼」をクリックして展開すると、pychaser 以外のライブラリを追加できます。

- **pychaser** はシステムにプリインストール済みです。アップロード不要です。
- 追加ライブラリは `.py` ファイル単体のみ対応します。
- チームごとに別々のライブラリを設定できます。

## 4. マップの設定

### 4-1. マップをアップロード

フッターの「アップロード...」ボタンで `.map` ファイルを読み込みます。

### 4-2. マップエディタで作成

「エディタ...」ボタンを押すと Canvas ベースのエディタが開きます。

| ツール | 操作 |
|---|---|
| **Nothing** | マスを空白にする |
| **Block** | 岩（ブロック）を配置する |
| **Item** | アイテムを配置する |
| **Start** | プレイヤーの初期位置を設定する |

- 「ランダム生成」ボタンで設定に基づいたマップを自動生成します
- 「保存」を押すとマップデータが反映されます

### 4-3. ランダムマップの設定

設定ダイアログ（⚙）の「ランダムマップ」タブで変更できます。

| 設定 | 初期値 | 説明 |
|---|---|---|
| ターン数 | 100 | 最大ターン数 |
| ブロック数 | 20 | 配置する岩の数（偶数推奨） |
| アイテム数 | 51 | 配置するアイテム数（奇数推奨） |
| 対称マップ | ON | 左右対称で生成する |

## 5. ゲームの開始と対戦表示

### 5-1. ゲーム開始

COOL と HOT の両方が **「準備完了」** になると、フッターの「ゲームスタート」ボタンが有効になります。クリックするとゲームが始まります。

### 5-2. 対戦表示ウィンドウの見方

ゲーム開始後、対戦表示ウィンドウに以下が表示されます。

```
┌────────────────────────────────────────────────────────────┐
│  [HOT名] [HOT得点 | 残りターン | COOL得点] [COOL名]        │ ← 上部バー
├──────────────┬────────────────────────────┬────────────────┤
│  COOL パネル │       ゲームボード          │  HOT パネル    │
│  ┌────────┐  │  (プレイヤーがターンごとに  │  ┌──────────┐  │
│  │ COOL   │  │   動き、1ターン経過後に    │  │  HOT     │  │
│  │勝ち点  │  │   次のターンへ進む)         │  │ 勝ち点   │  │
│  │スコア  │  │                            │  │ スコア   │  │
│  │B/P    │  │                            │  │ B/P     │  │
│  │アイテム│  │                            │  │アイテム  │  │
│  └────────┘  │                            │  └──────────┘  │
│  TOTAL合計   │                            │  TOTAL合計     │
├──────────────┴────────────────────────────┴────────────────┤
│  [行動中: COOL]         [残りアイテム数]      [アイテム数]  │ ← 下部バー
└────────────────────────────────────────────────────────────┘
```

| 表示 | 意味 |
|---|---|
| 上部バー中央 | HOT得点 \| 残りターン \| COOL得点 |
| 各パネルの「勝ち点」 | 1勝 = 3点（2試合制時に意味をもつ） |
| 各パネルの「スコア」 | アイテム数×10 + 残りターン数（勝者のみ）+ 全取りボーナス |
| 各パネルの「B/P」 | ボーナス/ペナルティ（現在は常に0） |
| 各パネルの「アイテム」 | スコアと同値（B/P=0の場合） |
| TOTAL 合計 | 両チームの勝ち点・スコア合計 |
| 下部バー左 | 行動中チームまたはゲーム結果 |
| 下部バー中央 | 残りアイテム数 |

### 5-3. 1ターンの表示時間

デフォルトでは **1ターンごとに1秒間** ボードが表示されてから次のターンに進みます。設定ダイアログで変更できます（詳細は「[8. 設定ダイアログ](#8-設定ダイアログ)」参照）。

### 5-4. ゲーム終了

ゲームが終了すると：
- **対戦表示ウィンドウ**: 下部バーに結果（WIN!/DRAW）が表示されます
- **コントロールウィンドウ**: 「セットアップに戻る」ボタンが表示されます

コントロールウィンドウで「セットアップに戻る」をクリックすると、対戦表示ウィンドウも「対戦開始をお待ちください」画面に戻ります。

### 5-5. セットアップ中の対戦表示ウィンドウ

ゲーム開始前の待機中も、対戦表示ウィンドウは以下の画面を表示します。

```
        U15 Server Maizuru
    対戦開始をお待ちください

  ┌──────────────┐  VS  ┌──────────────┐
  │     COOL     │      │     HOT      │
  │  プログラム名 │      │  プログラム名 │
  │  [準備完了]  │      │  [接続待ち]  │
  └──────────────┘      └──────────────┘

       ローカル IP: 192.168.1.9
```

チームが接続・準備完了になるたびに状態が自動更新されます。

## 6. 2試合制モード

先攻・後攻を入れ替えた2試合を行い、合計スコアで最終勝者を決定します。

### 有効化方法

1. コントロールウィンドウの ⚙ 設定ダイアログを開く
2. 「ゲーム」タブの「2試合制 (先後入れ替え)」をONにする
3. 保存する

コントロールウィンドウに「第1試合」バッジが表示されます。

### 2試合制フロー

```
[第1試合: COOL先攻・HOT後攻]
      ↓ ゲーム終了
  対戦表示: 結果表示
  コントロール: 「次戦スタート」ボタン表示
      ↓ クリック
  COOLとHOTのプログラムが自動入れ替え
  コントロール: 「第2試合」バッジ表示 → 「ゲームスタート」クリック
      ↓
[第2試合: COOL後攻・HOT先攻]
      ↓ ゲーム終了
  TOTAL 合計ポイントで最終勝者決定
```

- 両試合終了後、各パネルの「TOTAL 合計」に累計ポイントが表示されます
- コントロールウィンドウで「セットアップに戻る」をクリックするとリセットされます

## 7. 手動操作モード

### 操作方法

1. コントロールウィンドウのチームパネルで「手動操作」を選択する
2. 相手チームを CPU または TCP に設定する
3. 「ゲームスタート」を押す
4. 対戦表示ウィンドウのボード下部に操作パネルが表示される

### 操作パネル

```
┌──────────────────────────────┐
│ 手動操作 (COOL)  [入力待ち] │
│ アクション: [WALK▼]         │
│          [↑]                │
│    [←]  [↓]  [→]           │
│  キーボード: ↑↓←→ も対応  │
└──────────────────────────────┘
```

| アクション | 動作 |
|---|---|
| **WALK** | 方向に1マス移動（アイテムがあれば取得） |
| **LOOK** | 周囲を観察（移動なし） |
| **SEARCH** | 探索（移動なし） |
| **PUT** | 方向にブロックを設置 |

## 8. 設定ダイアログ

コントロールウィンドウの ⚙ ボタンで開きます。

### ゲームタブ

| 設定 | デフォルト | 説明 |
|---|---|---|
| TCP タイムアウト | 5秒 | クライアントの応答待ち時間 |
| 1ターンの表示時間 | 1.0秒 | ターンごとにボードを表示する時間（0 = 即時）|
| テクスチャテーマ | Jewel | Jewel / Light / Heavy / RPG から選択 |
| SE ミュート | OFF | 効果音をオフにする |
| 2試合制 | OFF | 先後入れ替え2試合モードを有効にする |

> **1ターンの表示時間について**: デフォルトは1.0秒です。0に設定するとCPU同士のゲームが一瞬で終了します。観客向けの表示には1〜2秒程度を推奨します。

### ランダムマップタブ

| 設定 | デフォルト | 説明 |
|---|---|---|
| ターン数 | 100 | 最大ターン数 |
| ブロック数 | 20 | 配置する岩の数（偶数推奨） |
| アイテム数 | 51 | 配置するアイテム数（奇数推奨） |
| 対称マップ | ON | 左右対称で生成する |

## 9. エラーと対処法

### 「プログラムの起動に失敗」

- Python がインストールされているか確認してください
- ファイルパスに日本語や特殊文字が含まれていないか確認してください
- `.py` ファイルが正しい pychaser プログラムか確認してください

### ポート使用中エラー

- 別のサーバーが起動していないか確認してください
- アプリを完全に終了してから再起動してください

### 「TCP接続待ち」のまま変わらない

- 相手のプログラムが指定ポート（12031/12032）に接続しているか確認してください
- ファイアウォールでポートがブロックされていないか確認してください

### プログラムがすぐ切断される

- pychaser のバージョンが対応しているか確認してください
- サーバーのコンソール（コントロールウィンドウのログ）でエラーを確認してください

### 対戦表示ウィンドウが応答しない

- コントロールウィンドウは正常に動作しているか確認してください
- 対戦表示ウィンドウは同じ WebSocket サーバーに接続しています。コントロールウィンドウが動いていれば、対戦表示も自動復旧します。

### ゲームが表示されないまま終わる

- 設定ダイアログで「1ターンの表示時間」が 0 秒になっていると一瞬で終了します
- 1.0秒以上に設定してから再試行してください
